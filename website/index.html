Good to know

Frequently asked questions

Is the cheat code inputter safe?

Yes. The app is open source and runs locally. It only simulates keyboard presses after you start it, and it does not collect personal data. Download it only from this website or the official GitHub repository.

Does this modify my game or save files?

No. It enters the same built-in cheat codes you could type yourself. It does not edit game files, memory, or save data.

Why does Windows show a warning?

The Windows build is currently unsigned, so Microsoft Defender SmartScreen may show an unverified publisher warning. The complete source and release process are public on GitHub.

Which operating systems are supported?

Prebuilt releases are available for 64-bit Windows and for 64-bit x86 or ARM Linux. macOS builds are not currently published.
